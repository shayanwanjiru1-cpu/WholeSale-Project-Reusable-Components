# WholeSale Project – Reusable Components

A reusable Svelte 5 + Tailwind CSS 4 component library for a single-page wholesale goods website.

## Getting started

```sh
npm install
npm run dev
```

Open `/components` to browse every component, variant and state.

## Structure

- `src/lib/components/` – reusable components (`layout`, `navigation`, `data-display`, `feedback`, `media`, `ui`)
- `src/lib/types`, `src/lib/utils` – shared types and helpers
- `src/app.css` – design tokens
- `src/routes/components` – component showcase (development only)
